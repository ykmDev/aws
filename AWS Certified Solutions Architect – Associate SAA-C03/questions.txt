1) You have an e-commerce application with an OLTP database hosted on-premises. 
This application has popularity which results in its database has thousands of requests per second.
You want to migrate the database to an EC2 instance. Which EC2 Instance Type should you choose to 
handle this high-frequency OLTP database?
Compute Optimized
Storage Optimized
Memory Optimized
General Purpose
ans: Storage Optimized because:
Storage Optimized EC2 instances are great for workloads requiring high, 
sequential read/write access to large data sets on local storage.

For compliance purposes, you would like to expose a fixed static IP address to your end-users so that 
they can write firewall rules that will be stable and approved by regulators. 
What type of Elastic Load Balancer would you choose?
1. ALB with Elastic IP attached to it.
2. NLB

ans: NLB.
because ALB can't attach Elastic IP.
NLB has one static IP address per AZ. can attach Elastic IP.
ALB and Classic LB have static DNS name.

You have an Auto Scaling Group fronted by an Application Load Balancer. 
You have configured the ASG to use ALB Health Checks, then one EC2 instance has just been reported unhealthy. 
What will happen to the EC2 instance?

1. ASG will keeep the instance running and re-start the application
2. ASG will detach the EC2 instance and leave it running
3. ASG will terminate EC2 instance

ans: 3. ASG will terminate EC2 instance
because we can configure ASG to check LB' health checks instead of EC2 status check(default)
